# 使用说明

image-studio 是本地图片生成器——文生图、图生图（传统重绘 / 多参考图
智能编辑）、图库管理、任务队列，全部推理由共享的 ComfyUI 常驻服务完成。

## 一、启动

前置：本机有常驻 ComfyUI 服务（任意 ComfyUI 安装均可，默认 http://127.0.0.1:8188），
默认 `http://127.0.0.1:8188`。

```bash
npm install
cp .env.example .env     # 按需修改 COMFYUI_URL / 模型文件名
npm start                # http://127.0.0.1:8030
```

右上角状态徽章显示 ComfyUI 连接状态（绿=已连接，15 秒自动刷新）。

## 二、生成

### 文生图

1. 输入**提示词**（中文一句话即可；建议英文专业描述效果更佳）
2. 可选：**负面提示词**——不想要的内容（如"模糊、低质量"）
3. 选择尺寸预设 / 步数 / 引导系数 / 生成张数 / 种子
4. 点「开始生成」（同步等待）或「后台生成」（入队继续操作）

生成按钮下方实时显示**耗时估算**：

> 预估 128.4s · 1.05MP · 约 6.17GB 显存 · RTX 5090（按本机近 5 次出图实测校准）

估算基于本机历史出图自动校准，无记录时回退保守参考值并明确标注。

### 图生图（三种参考方式）

切到「图生图」后添加参考图（最多 **9 张**，3×3 宫格，点击/多选/拖拽，
第 1 张是画布——输出尺寸跟随它）：

| 方式 | 说明 | 提示词作用 |
|:---|:---|:---|
| 自动（默认） | 1 张→传统重绘，多张→智能编辑 | — |
| 智能编辑 | Qwen-Image 2.1 原生多参考图融合，全部参考图同时"喂"给模型 | **提示词即编辑指令**：`把 <image2> 的人物放进 <image1> 的场景`（`image_1`/`第1张` 等写法自动归一化） |
| 传统重绘 | 只用第 1 张图编码回 latent，按重绘强度降噪 | 常规描述 + 负面提示词均生效 |

提示词下方有 `<1>`~`<9>` 一键插入引用按钮。

### 画布

生成结果以**大图**展示；多张生成时底部出现**缩略图条**（本次批次），
点击切换主图。点击大图打开详情。

## 三、图库

- 点缩略图 → **详情弹窗**：大图 + 完整元数据（提示词/负面、尺寸、
  步数、种子、耗时、时间、通道），可下载、删除
- **收藏**：图库卡片 ☆/★ 切换，`?favorite=1` 过滤
- **多选模式**：右上「选择」→ 勾选图片 → 底部批量条：
  - **打包下载**：选中图片打成一个 zip
  - **批量删除**：删记录 + 删文件（带确认）

## 四、任务

- 分页标题显示活动任务数：**任务（2）** = 排队 + 运行中
- 列表 3 秒自动刷新（状态/进度实时可见，无需切页）
- 点行或「详情」→ 弹窗：状态、进度、参数快照、产物缩略图、错误信息、删除
- **多选模式**：勾选后批量删除（运行中的会被取消）

## 五、提示词工具（右上角按钮）

### 提示词管理

两个分页——**常用提示词 / 常用反向提示词**：

- **新增**：文本域输入保存
- **查询**：搜索框实时过滤
- **替换到输入框**：按分页写入主提示词/负面提示词框（累计使用次数，
  列表按频次排序）
- **编辑 / 删除**：逐条操作

### 反向推导提示词

从图片反推提示词（复用出图自带的 Qwen3-VL 视觉塔，本地推理，
不联网、无额外模型）：

1. 点击/拖拽选择图片
2. 点「推导」（约 20 秒至几分钟）
3. 结果文本框下方三个操作：
   - **复制到剪贴板**
   - **保存到常用提示词**（入库，与提示词管理联动）
   - **替换提示词**（写入主提示词输入框）

### 模型管理

以 ComfyUI 实际可见列表（object_info）为准的三类模型选择
（扩散模型 / 文本编码器 / VAE），选择即时生效并写入 .env，
下一张图使用新权重。

## 六、常见问题

**Q：耗时估算差很多？**
首次无本机记录时用 RTX 2060 参考值（偏保守）；完成首次生成后自动
按本机实测校准，样本越多越准。

**Q：智能编辑结果尺寸不对？**
编辑通道输出尺寸跟随 image_1（画布），请把画布放在第 1 张。

**Q：负面提示词没效果？**
智能编辑通道官方约定 CFG=1，负面提示词不参与引导——输入框占位
文字有提示。传统重绘与文生图正常生效。

**Q：ComfyUI 未连接？**
确认 comfy-service 已启动（`./status.sh`），`.env` 里 `COMFYUI_URL`
指向正确地址。

**Q：参考图上传失败？**
长边超 1536 的图会自动压缩；确认图片格式为常见格式（png/jpg/webp）。

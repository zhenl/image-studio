# 模型预设（一套配置带齐模型三件 + 参数约定）

## 为什么需要

切换模型不只是换文件名：**参数约定必须同步**。z-image-turbo / Qwen-Image
2.1 Turbo 都是 8 步蒸馏模型，CFG=1；而主力 Qwen-Image 2.1 要
引导系数 4（负面提示词才生效）。只换模型不改参数 → 出图质量断崖。

预设把「三件模型文件 + 步数/引导默认值 + 使用提示」打包，一次切换全部生效。

## 预置

| id | 三件模型 | 参数约定 | 实测 |
|:---|:---|:---|:---|
| `qwen-2.1` | Q4_K_M GGUF + qwen3vl_8b_int8 + qwen_image_2.1_vae | 8 步 / CFG 4.0（负面生效） | ~2 分钟/张 |
| `qwen-2.1-turbo` | qwen-image-2.1-turbo-int8_convrot + 同编码器/VAE | 8 步 / **CFG 1.0**（负面无效） | 11~22s/张，编辑通道保留 |

## 接口

- `GET /api/v1/models/presets` → `{current, presets[]}`
- `POST /api/v1/models/preset/select` `{id}` → 校验 ComfyUI 可见性
  （缺文件返回 422 MODEL_MISSING 并列出缺失项）→ 应用运行时配置 →
  写回 `.env` 持久化

## 前端

顶栏下拉框：选中后模型立即切换，并把步数/引导系数滑块的默认值同步
为预设约定（超过 1 的引导系数同时影响“CFG=1 负面不生效”提示的显隐），
最后刷新状态徽标。

## 已知坑

- ComfyUI 停机时切换会报「看不到模型」——预设校验依赖
  `/object_info`，属预期行为（比静默失败好）
- `.env` 写回意味着重启后保留选择；想回默认改 `.env` 或用预设切回
